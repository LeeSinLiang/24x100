# Judge panel

Four fresh agents, each given one persona, the README, `STORYBOARD.md` and the running production build
(`npm run build && npm run preview`, http://localhost:4173/), and told not to read the source. Each scored six
criteria from 1 to 5 with evidence they saw themselves, timed the first-run task ("What blocks 2241 Mahon St,
and what would unlock it?", from the bare home page), and listed bugs. The prompts are in
`.scratch/judge-*.md` (not committed; the persona text is quoted below). These are AI agents role-playing
judges, not people: treat the scores as a structured review, not as a prediction of the real panel.

Round 1 judged the build of commit `4e30c6b` (Sat 26 Sep, 18:10), which had spec §0.12 (money first, no
score) but not yet §0.13 (one cost estimate, "what's left after building"); the judges' money figures
($325–$375/sf, "gap at least $83,000") are from that build and have since been replaced.
